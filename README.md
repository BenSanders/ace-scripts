# ACE Scripts

This is a collection of scripts that I plan to work on to help people who wish to run a private Asheron's Call server.

It uses ACEmulator found at [https://github.com/ACEmulator/ACE](https://github.com/ACEmulator/ACE).

The general order to run these scripts are as follows:

* `install-docker.sh`
* `configure-ace-server.sh`
* `start-ace.sh`

My hope is to make the second script able to take user input for their chosen MySQL passwords to go into the docker.env.

At the moment this is being tested on Ubuntu 24.04 LTS.
